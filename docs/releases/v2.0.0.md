# LightNovelSelector v2.0.0 更新说明

发布日期：2026-07-24

## 本轮重点

`v2.0.0` 完成从旧 WebView 桌面层到 WinUI 3 的全面迁移，并把 Windows 交付方式改为单个安装 EXE。分类语义与 Python Sidecar 协议保持兼容。

## 原生界面与安装

- 桌面界面改用 WinUI 3 与 Windows App SDK。
- 支持 Acrylic、Mica、实色材质，默认跟随 Windows 深浅色和减少动态效果。
- 新增搜索、系列筛选、状态筛选、详情、手动修正、活动报告和核心重连。
- 发布版改为 `LightNovelSelector-v2.0.0-win-x64-setup.exe`，按当前用户安装，不要求管理员权限。
- 安装器包含 .NET、Windows App SDK 和冻结后的 Python Sidecar，普通用户不需要另装开发环境。
- 旧 WebView 最终版本保存在 `legacy-webview-final` 标签和 `legacy/webview-v2` 分支。

## 文件安全

- 重复检测使用完整文件内容哈希确认。
- 扫描与筛选不会改变最终执行范围，移动前必须经过用户确认。
- 目标冲突不会覆盖已有文件，重复项和错误项默认跳过。
- 文件移动部分失败时仍保存可撤销报告。
- 设置保存失败采用 best-effort，不阻断扫描。
- Sidecar 支持一次自动恢复和手动重连，恢复后不会自动重新扫描或移动。
