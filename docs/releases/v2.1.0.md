# LightNovelSelector v2.1.0 更新说明

发布日期：2026-08-02

## 本轮重点

`v2.1.0` 是一次覆盖识别、文件安全、批量性能、原生界面和可信发布的完整升级。
软件继续采用 WinUI 3 原生界面与 Python 分类核心，保留“先预览、再整理、可撤销”
的工作方式，不改变已有分类报告和撤销流程的兼容边界。

## 识别与人工修正

- 统一识别标题、系列、作者、卷号、语言和标签，并在详情中展示分类依据。
- 加强中日英标题、全半角字符、中文数字、罗马数字、日文卷号、作者后缀和副标题归一化。
- 置信度使用统一的保守标尺，并区分高、中和需要复核，不再只显示来源原始分数。
- 用户明确保存的系列修正会形成仅保存在本机的别名记忆，后续精确命中时优先复用。
- 支持比较本地与在线候选；同系列批量修正默认关闭，启用时仍需二次确认。
- Bangumi、AniList 和 Jikan 采用可扩展来源接口，可分别启停、排序并查看健康状态。

## 文件整理与异常恢复

- 重复文件先用快速签名分组，再以完整 SHA-256 确认，避免相同头尾内容造成误判。
- 整理前重新核对源文件、目标路径、文件状态和分类根目录，拒绝链接替换与路径越界。
- 每次移动前把恢复意图立即写入磁盘；中途失败或进程被强制结束后仍可重建报告。
- 撤销前先检查整批记录，遇到源与目标同时存在、同时缺失或内容变化时停止猜测。
- 活动页保留多个分类批次，可查看、导出或安全撤销指定批次。
- 极端 Unicode 文件名、损坏 EPUB、畸形协议消息和文件移动故障均有自动边界测试。

## 大型书库与稳定性

- 建立 10,000 文件冷扫描、热扫描、取消响应、内存与缓存复用性能预算。
- 本地基准中 10,000 文件热扫描由约 17.5 秒降至约 8.5 秒。
- 在线来源使用独立限流、失败冷却和短期负缓存；单一服务异常不会拖住整批扫描。
- 分类核心连接具有连接中、可用、恢复中和已断开状态，可自动恢复一次或手动重新连接。
- 核心重连不会静默重跑扫描或文件移动，避免旧预览被误执行。

## WinUI 3 界面

- 默认跟随 Windows 深浅色，并提供 Acrylic、Mica 和实色三档窗口材质。
- 高对比度或系统关闭透明效果时自动回退系统实色，不牺牲文字可读性。
- 新增一次性的“先预览，再整理”首次使用提示，并可从标题区随时重新打开。
- 宽窗口并排显示结果与详情；紧凑窗口使用可收起侧栏，低高度下可滚动到确认区。
- 完善搜索、系列与状态筛选、来源健康面板、历史报告和异常恢复入口。
- 页面、筛选、详情、报告与设置补齐键盘快捷键、焦点顺序和屏幕阅读器名称。
- 进入、Toast、按压和进度反馈使用短时非线性缓动；减少动态效果时取消非必要位移。

## 安装包与发布可信度

- 移除未使用的 Windows AI、ML、Widgets 与 DWrite 运行组件，保持完整自包含安装。
- 安装器体积由约 72.5 MB 降至约 56.4 MB，用户仍无需另装 Python、.NET 或 Windows App SDK。
- 每次正式发布同时提供安装器、`SHA256SUMS.txt`、SPDX SBOM 和结构化构建信息。
- GitHub 标签流水线会验证版本、主分支来源、中文说明、资产哈希和 SBOM，并生成构建来源证明。

## 验证结果

- Python：236 项测试、746 组参数化与故障注入子样本通过。
- C#：72 项测试通过，包括真实 Python Sidecar 强制退出与重连。
- Ruff、Mypy、Bandit、Vulture、pip-audit、PSScriptAnalyzer、actionlint 和依赖审计通过。
- WinUI Debug / Release x64：0 警告、0 错误。
- 源码启动、完整外观、1024×700 紧凑详情和自包含安装器冒烟测试通过。
- GitHub Windows CI 与 Python/C# CodeQL 检查通过。

## 兼容性

- 支持 Windows 10 1809 或更高版本以及 Windows 11。
- 正式安装器面向 Windows x64，并包含所需运行环境。
- 分类报告保持 schema v2，Sidecar 协议保持兼容。
- 旧版 `classification_report.json` 仍可在原分类目录中撤销。

## 已知限制

- 安装器目前没有商业代码签名证书，Windows 可能显示“未知发布者”。请只从本仓库 Release 下载。
- 当前没有单独的 Windows ARM64 安装器。
- 在线元数据依赖第三方服务；不可用时会回退本地规则，不影响本地文件整理。
